# TaskFlow — Modern Task Manager Application

A modern, responsive, and robust Task Management application built with **React 18**, **TypeScript**, and **Pure Normal CSS (Vanilla CSS)** without any Tailwind CSS dependencies. All source code files are organized directly within **one single flat folder** (`src/`) with zero subdirectories.

---

## 🚀 Quick Start & Commands

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)

### 1. Run the Automated Test Suite
To execute the unit and integration tests (powered by Vitest & React Testing Library):
```bash
# Run all tests once
npm test

# Run tests in interactive watch mode
npm run test:watch
```

### 2. Start the Local Development Server
```bash
npm run dev
```
Open `http://localhost:3000` (or `http://localhost:5173`) in your browser.

### 3. Build & Preview Production Bundle
```bash
npm run build
npm run preview
```
